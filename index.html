    mp3 · m4a · wav · ogg · flac — khoảng trắng tự biến thành dấu _
    Làm sao để lấy token upload? GitHub Pages là trang tĩnh, nên trang này dùng GitHub API để tự commit tệp nhạc vào repo thay bạn:
    1. Vào github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Chọn đúng 1 repo này, thời hạn tùy ý.
    3. Mục Repository permissions → Contents: chọn Read and write.
    4. Dán token vào ô phía trên rồi LƯU CÀI ĐẶT.

    ⚠️ Token nằm trong trình duyệt của bạn (localStorage) và repo phải public. Chỉ dùng token giới hạn đúng 1 repo. Sau khi upload, chờ Pages build lại ~1 phút rồi bấm LÀM MỚI.

    Có token thì thứ tự kéo-thả, bài ẩn và các danh sách phát đều được lưu vào music/playlist.json trên repo — giữ nguyên cho mọi người truy cập.
