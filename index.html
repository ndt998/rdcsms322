    Kéo thả tệp nhạc vào đây, hoặc nhấn để chọn

    mp3 · m4a · wav · ogg · flac — khoảng trắng tự biến thành dấu _
    Làm sao để lấy token upload? GitHub Pages là trang tĩnh, nên trang này dùng GitHub API để tự commit tệp nhạc vào repo thay bạn. Cách lấy token:
    1. Vào github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Chọn đúng 1 repo này, thời hạn tùy ý.
    3. Mục Repository permissions → Contents: chọn Read and write.
    4. Dán token vào ô phía trên rồi LƯU CÀI ĐẶT.

    ⚠️ Token nằm trong trình duyệt của bạn (localStorage) và repo phải public. Chỉ dùng token giới hạn đúng 1 repo — đừng dùng token full quyền. Sau khi upload, chờ GitHub Pages build lại ~1 phút rồi bấm LÀM MỚI.

    Có token rồi thì thứ tự kéo-thả và các bài bị ẩn cũng được lưu thẳng vào repo (file music/playlist.json) — giữ nguyên cho mọi người truy cập.
